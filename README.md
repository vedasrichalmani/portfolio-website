# Chalmani Veda Sri — Personal Portfolio

## About
Responsive student portfolio for Chalmani Veda Sri, a Computer Science Engineering student interested in software development, problem solving, and technology.

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6+

## Features
- Responsive portfolio and Bootstrap navigation
- Dark/light mode with saved preference
- JavaScript project filtering
- Contact form validation (frontend only; no messages are sent)
- Education timeline, skills, certifications, activities, interests, and languages

## Project Structure
- `index.html` — semantic page content and portfolio sections
- `css/style.css` — theme variables, layout, and responsive styling
- `js/script.js` — theme switcher, navigation state, project filter, and form validation
- `images/profile.svg` — abstract avatar illustration
- `images/README.txt` — notes for replacing or adding image assets

## How to Run
Open `index.html` directly in a browser, or open the folder in VS Code and use the Live Server extension.

## Customization
Edit `index.html` to change the name, email, education, skills, certifications, activities, interests, and language details. Replace the clearly labeled project placeholders with real project information and working links. Social links are omitted until actual profile URLs are available. Update `css/style.css` to customize colors and layout; update `js/script.js` to modify interactions and validation.
